# История изменений

Заметные изменения DownloadLib по версиям. Готовые сборки и описания прошлых версий — в [Releases](https://github.com/ivanvit100/DownloadLib/releases).

## 1.1.0

Версия с переработанной архитектурой: загрузка стала устойчивее к медленным страницам, лимит запросов — общим для всего расширения, а плагины версий 1.0.x работают без изменений.

### Новое

- **Ограничение части файла по числу глав.** В настройках, в разделе «Ограничение части файла», можно выбрать «По размеру» или «По числу глав». По умолчанию в части не больше 50 глав.
- **Фоновая дозагрузка.** Картинка или глава, которая грузится дольше 30 секунд, больше не задерживает остальные главы тома. На её место ставится метка вроде «[Изображение N загружается в фоне]», а загрузка продолжается в фоне. Следующий том начинается, когда догрузился предыдущий; в это время в статусе видно «Дозагрузка в фоне: осталось N...». Если догрузить не удалось, в файле остаётся «[Ошибка загрузки изображения N]».
- **Один лимит запросов на всё расширение.** Лимит в минуту из настроек действует сразу на все запросы к сервису из всех окон расширения. Ответ сервера 429 притормаживает все окна одновременно.

### Изменено

- Лимит запросов применяется точно: раньше действовал лимит на единицу меньше введённого. Допустимые значения — от 2 до 200, по умолчанию 85.
- Кнопка «Скачать» на сайте и окно загрузки больше не меняют сохранённые настройки: выбранные в них параметры действуют только на эту загрузку.
- Диапазон глав передаётся в окно загрузки ключами глав, а не позициями в списке, поэтому скачиваются именно выбранные главы.
- Если вкладку сайта закрыли во время загрузки, запросы продолжаются через другую открытую вкладку того же сайта.
- Блокировка рекламных запросов переведена на правила declarativeNetRequest, поэтому работает и в Chromium-браузерах. Правила действуют только для запросов со страниц поддерживаемых сайтов.
- Токены авторизации хранятся в сессионном хранилище браузера: в Chrome они больше не теряются, когда фон расширения выгружается, и по-прежнему удаляются при закрытии браузера.
- Уже сохранённые части файла освобождают память, поэтому длинные загрузки расходуют её меньше.
- Ошибки сервиса показываются по-русски и с причиной: «Ошибка API (…): HTTP …», «Сетевая ошибка при запросе к API …», «Сервер отклонил авторизацию (…): войдите на сайт и повторите».
- Минимальные версии браузеров: Firefox и Firefox для Android 115, Chromium 102.

### Исправлено

- Если выбранные главы не найдены в списке глав тайтла, загрузка не запускается и показывается сообщение «Выбранные главы не найдены…». Раньше в этом случае мог получиться пустой или чужой файл.
- Тайтл без глав завершается ошибкой «Нет глав для загрузки», а не пустым файлом.
- Если файл не удалось собрать или сохранить, загрузка останавливается с ошибкой и не продолжает следующие части.
- Токен авторизации с сайта сервисного плагина больше не подменяет токен MangaLib.
- Истёкшие токены авторизации не используются, а после ответа сервера 401 токен сбрасывается.

### Безопасность

- Название и описание тайтла выводятся как текст, а не как HTML.
- Фон расширения принимает сообщения только от страниц самого расширения и от вкладок поддерживаемых сайтов.
- В Firefox заголовок `Access-Control-Allow-Origin` для картинок добавляется только для сайтов сервисов и самого расширения.

### Удалено

- Режим «Обновление книг» — дополнение уже скачанного файла недостающими главами.

### Для авторов плагинов

Контракт плагинов сохранён: плагины версий 1.0.x работают без изменений. Что гарантируется, описано в разделе [«Контракт плагинов»](ARCHITECTURE.md#контракт-плагинов). Изменения, которые плагины могут заметить:

- сервисные плагины учитывают `splitLongImages`/`maxImageHeight` и галочку «Разделять страницы»: длинные страницы режутся так же, как в MangaLib;
- у глав в данных `export()` появилось поле `key`, у частей разрезанной страницы — `partIndex` и `totalParts`;
- после того как промис `export()` разрешился и файл сохранён, расширение освобождает `content` глав пакета;
- `globalRateLimiter` стал обёрткой над общим лимитом фона: `acquire`/`trackRequest` ждут разрешения общего ограничителя, `throttle` блокирует запросы всех окон;
- `stripHtml` раскодирует `&amp;` последним: `&amp;lt;` превращается в текст `&lt;`, а не в `<`;
- `BaseService.loadPageAsBase64` снова работает;
- `EventBus.once` срабатывает ровно один раз, даже если колбэк бросил ошибку или повторно эмитит то же событие.

### Для разработчиков

- Код переведён на нативные ES-модули без сборки. Content scripts, `sandbox.js` и `sw.js` остаются классическими скриптами.
- Домены сервисов задаются только в `config.js` сервиса, content scripts регистрируются динамически.
- Логи пишутся через `createLogger` с уровнями `debug`/`info`/`warn`/`error`; как включить подробные логи, описано в [CONTRIBUTING.md](CONTRIBUTING.md#стиль-кода).
- `npm run lint` проверяет весь проект, CI запускает ту же команду.
